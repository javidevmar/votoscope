# Tareas — `web_scaffold`

Feature 16 de [`feature_list.json`](../../feature_list.json). Orden TDD: cada test nace antes que el código que lo hace verde. El `implementer` marca `[x]` al completar cada task; el `reviewer` rechaza si queda alguna `[ ]` sin justificación. Los tests de cada capa usan su runner: pytest en `ingestor/tests/`, `node --test` en `web/tests/` (ver `design.md` §D8). No se toca `feature_list.json` (lo actualiza el leader); el README **raíz** y `.agents/status.md` son de la feature 17.

Regla dura del BFF: ningún test puede quedar verde si hay SQL, `pg` o llamadas a servicios externos fuera de `web/app/api/` (R4).
